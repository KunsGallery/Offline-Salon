# Offline Salon Core

Offline Salon은 매달 코드를 교체하는 단일 행사 페이지가 아니라, 공통 운영 기능 위에 행사별 참여 활동을 추가하는 플랫폼으로 운영한다.

## 고정 코어

- 세션 생성과 상태 관리
- 포스터 기반 테마
- QR 참여와 닉네임·캐릭터 대기방
- 관리자 데스크톱과 모바일 리모컨
- 질문·설문·응답 수집
- 선택형 좋아요 투표
- PDF 발표와 화면 제어
- 참여자별 결과 갤러리
- 응답 기록, 숨김, 삭제, CSV 내보내기

새 세션은 `platform: offline-salon-core`로 정규화한다.

## 범용 참여 콘텐츠

기본 콘텐츠 단위는 `question`과 그에 속한 `response`다. 질문 타입과 관계없이 다음 옵션을 사용할 수 있다.

- `likesEnabled`: 다른 참여자 응답에 좋아요 투표 허용
- `includeInGallery`: 해당 질문의 공개 응답을 결과 갤러리에 포함

응답은 텍스트, 선택지, 단어 등 현재 지원하는 모든 값 형식을 그대로 사용한다. 이후 이미지·파일 응답을 추가하더라도 같은 응답 계약을 확장한다.

## 결과 갤러리

결과 갤러리는 두 종류의 콘텐츠를 함께 보여준다.

1. 참여자 결과: `includeInGallery`가 켜진 질문의 공개 응답을 참여자별로 묶어 표시
2. 세션 이미지: 관리자가 미리 등록한 이미지 자료를 동일한 갤러리 안에서 표시

참여자 결과 카드에는 닉네임, 캐릭터, 질문, 제출 결과, 좋아요 수가 포함된다. 여러 활동에서 같은 참여자가 만든 결과는 한 카드에 시간순으로 모인다.

## 지난 모임 호환

`artwork-title` 질문, 제목 채택, 제목 이력은 지난 모임 기록을 재생하기 위한 레거시 기능으로 유지한다. 새 Core 활동의 기본 계약에는 포함하지 않는다. 결과 갤러리에 포함할 Core 질문이 없는 과거 세션은 기존 작품 갤러리를 그대로 렌더링한다.

## 다음 달 활동 추가 계약

다음 달 특별 활동은 아래 네 화면만 Core에 연결하면 된다.

1. 관리자 설정: 활동 자료와 옵션 입력
2. 참여자 화면: 제출 또는 상호작용
3. Host 화면: 현장 시각화
4. 리모컨 화면: 시작·종료·화면 전환

활동 결과가 일반 응답이라면 `likesEnabled`와 `includeInGallery`를 그대로 재사용한다. 새로운 결과 형식이 필요할 때만 응답 값의 구조와 갤러리 렌더러를 확장한다.
