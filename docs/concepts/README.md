# Zodiac character concepts

The sheets record the visual direction for the reusable salon guests. The app renders the transparent production sprites in `public/avatars/` rather than the full reference sheets.

- `zodiac-victorian-01.png`: rat, ox, tiger, rabbit, dragon, snake
- `zodiac-victorian-02.png`: horse, sheep, monkey, rooster, dog, pig
- `zodiac-personalities-01.png`: rat through snake with species-specific interests and clothing
- `zodiac-personalities-02.png`: horse through pig with species-specific interests and clothing

Each species has a male-presenting and female-presenting salon guest, left to right. The illustration combines the everyday salon-guest direction with late-Victorian London clothing inspired by the Sherlock Holmes setting. Detective P and the retriever assistant remain separate named characters.

`public/avatars/zodiac-01.webp` and `zodiac-02.webp` are transparent 4-column by 3-row sprite sheets. Each adjacent pair is the male-presenting and female-presenting look for one species. `public/avatars/props.webp` is a separate 4-column by 3-row transparent sheet: four reusable salon props, seven PEAR PLAY detective props, and one exhibition-grape prop. The character identity and chosen reusable prop remain independent of the module-specific prop in saved avatar version 3. Previously saved vector avatars remain on version 2 until the participant opts into a new animal character.
