# 9월 모임 — 참여자가 만드는 전시 포도

## 운영 방식

참여자는 모바일에서 두 가지 방식으로 자기 포도알을 만든다.

1. `참고 전시에서 고르기`에서 서울 전시 리스트를 검색·필터링해 선택한다.
2. 리스트에 없으면 `직접 입력` 또는 `직접 전시 추가`로 전시명과 장소를 적는다.
3. 휴대폰 갤러리에서 전시 때 찍은 사진을 고르거나 현장에서 촬영한다.
4. `보고 싶어요 / 기대 중이에요 / 보고 왔어요`와 기대감·만족도 1~10을 정한다.
5. 저장하면 개인 포도, Host 화면, 진행자 통계에 즉시 반영된다.

선택한 사진은 브라우저에서 긴 변 1440px JPEG로 줄인 뒤 R2에 저장한다. 사진 원본 전체를 올리지 않아 모바일 데이터와 저장 공간을 줄인다.

## 참고 전시 리스트

기본 리스트는 2026년 5월부터 11월 사이 서울에서 볼 수 있거나 관심 대상으로 삼을 수 있는 전시를 담는다. 각 전시에는 다음 분류가 있다.

- 지역: 한남·용산, 삼청·종로, 중구·시청, 여의도, 잠실·송파, 북서울 등
- 월: 전시 기간과 겹치는 5월–11월
- 작가 분류: 국내 작가, 국외 작가, 국내·국외 혼합
- 태그: 회화, 설치, 미디어, 사운드, 고미술, 공공미술 등

관리자는 `세션 준비 → 세션 준비실 → 참고 전시`에서 기본 리스트를 확인하고, 필요한 전시를 직접 추가할 수 있다. 직접 추가한 전시도 참여자 선택지와 통계에 포함된다.

## 테스트 방법

1. 관리자 화면에서 전시 포도 모듈이 켜진 세션을 만들고 `전시 포도 시작`을 누른다.
2. 참여 QR로 휴대폰 두 대 이상을 접속하고 각자 닉네임을 만든다.
3. 한 명은 참고 전시에서 선택하고, 다른 한 명은 직접 입력으로 전시를 등록한다.
4. 같은 전시를 집계하려면 같은 참고 전시를 선택하거나 전시 이름과 장소를 동일하게 적는다.
5. Host 화면에서 `실시간 전시 카운터`, `참여자 전시 포도`, `전체 포도밭`을 차례로 확인한다.

실제 행사 전에 Firebase Console의 `Authentication → Sign-in method → Anonymous`를 활성화해야 한다. 익명 로그인 토큰으로 참여자마다 제한된 R2 업로드 주소를 발급하므로 관리자 계정이나 R2 비밀키는 참여자에게 노출되지 않는다.

## 저장과 Host 집계

각 참여자 문서의 `grapeSelections`에 사진 URL, 참여자가 작성한 정보, 참고 전시 분류를 함께 저장한다.

```js
grapeSelections: {
  grapeId: {
    id: 'grapeId',
    title: '전시 이름',
    venue: '장소',
    photoUrl: 'https://R2-public-url/.../photo.jpg',
    photoPath: 'sessions/.../grape/.../photo.jpg',
    status: 'want' | 'expecting' | 'seen',
    rating: 1,
    referenceId: 'optional-reference-id',
    region: '삼청·종로',
    monthTags: [8, 9, 10],
    artistOrigin: 'domestic' | 'international' | 'mixed',
    categoryTags: ['회화', '동시대'],
    source: 'participant' | 'reference',
    createdAt,
    updatedAt,
  }
}
```

Host는 전시 이름과 장소 또는 참고 전시 ID로 자동 집계한다. 진행자 화면과 Host의 실시간 화면은 지역별, 월별, 국내/국외 작가별 선호를 함께 보여준다.

## 화면 구성

- `실시간 전시 카운터`: 참여자가 만든 전시 카드를 모으고 참여 인원을 플립 숫자로 표시
- `분류별 통계`: 지역, 월, 작가 분류 기준으로 선택 수와 평균 기대감·만족도를 요약
- `참여자 전시 포도`: 한 사람이 직접 찍은 사진으로 채운 포도와 전시 목록 표시
- `전체 전시 포도밭`: 결과가 있는 모든 참여자의 포도송이를 하나의 줄기에 배치
