# 9월 모임 — 전시 포도

## 활동 흐름

1. 관리자가 `세션 준비실 → 갤러리 이미지`에 전시 포스터와 전시명을 등록한다.
2. 각 전시의 `NFC 카드 주소`를 복사해 NFC 카드에 URL 레코드로 기록한다.
3. 관리자가 `전시 포도 시작`을 누르면 참여자 모바일에는 개인 포도송이, Host에는 실시간 전시 카운터가 열린다.
4. 참여자는 NFC 카드를 태그하거나 전시 목록을 눌러 `보고 싶어요 / 기대 중이에요 / 보고 왔어요`를 선택한다.
5. 기대감 또는 만족도를 1~10으로 지정하면 포스터가 개인 포도의 한 알로 열린다.
6. 관리자 리모컨에서 한 참여자의 포도 또는 전체 참여자의 포도밭을 Host에 띄워 함께 이야기한다.

## NFC 방식

카드에는 다음 형태의 URL을 NDEF URL 레코드로 기록한다.

```text
https://salon.unframe.kr/client/{sessionId}?exhibition={exhibitionId}
```

- iPhone: 잠금이 풀린 상태에서 카드를 태그하면 Safari로 해당 전시 기록 화면이 열린다.
- Android: 카드 URL 방식이 동일하게 동작한다.
- Android Chrome 지원 기기: 참여자 화면의 `연속 스캔` 버튼으로 페이지를 유지한 채 여러 카드를 연속으로 읽을 수 있다.
- NFC를 사용할 수 없는 경우에도 참여자 화면의 전시 목록에서 같은 활동을 수행할 수 있다.

Web NFC API는 HTTPS, 사용자 동작, NFC 권한과 화면 표시 상태가 필요하며 Chrome for Android 중심이다. Safari는 Web NFC API를 제공하지 않으므로 행사 기본 방식은 반드시 NFC URL 카드로 운영한다.

## 저장 구조

전시 목록은 기존 세션 이미지(`session.artworks`)를 재사용한다. 참여자 선택은 각 참여자 문서의 `grapeSelections`에 전시 ID별로 저장한다.

```js
grapeSelections: {
  exhibitionId: {
    exhibitionId,
    status: 'want' | 'expecting' | 'seen',
    rating: 1,
    tapCount: 1,
    createdAt,
    updatedAt,
  }
}
```

동일 참여자가 같은 전시를 다시 태그하면 기존 포도알을 수정하고 `tapCount`를 올린다. Host의 기본 카운터는 반복 태그 수가 아니라 해당 전시를 포도에 담은 참여자 수를 보여준다.

## Host 화면

- `실시간 전시 카운터`: 모든 전시 포스터와 선택 인원을 플립 숫자로 표시
- `참여자 전시 포도`: 선택한 참여자의 포도송이와 전시 목록을 크게 표시
- `전체 전시 포도밭`: 결과가 있는 모든 참여자의 포도송이를 하나의 줄기에 배치

## 디자인 규칙

- 원형 포도알 안에 전시 포스터를 넣는다.
- 기대감·만족도 1~10에 따라 차가운 보라에서 짙은 와인색으로 변화한다.
- 색상과 함께 숫자를 항상 표시해 색각에만 의존하지 않는다.
- 포도 잎과 줄기는 선명한 벡터 도형으로 렌더링하고 실제 콘텐츠인 포스터가 시각적 중심이 되게 한다.
