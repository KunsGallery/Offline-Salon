# 9월 모임 — 참여자가 만드는 전시 포도

## 사전 전시 등록은 필요 없다

관리자가 전시 목록이나 포스터를 미리 입력하지 않는다. 참여자는 모바일에서 다음 순서로 자기 포도알을 직접 만든다.

1. `사진으로 전시 추가`를 누른다.
2. 휴대폰 갤러리에서 전시 때 찍은 사진을 고르거나 현장에서 촬영한다.
3. 전시 이름과 선택 사항인 장소를 직접 적는다.
4. `보고 싶어요 / 기대 중이에요 / 보고 왔어요`와 기대감·만족도 1~10을 정한다.
5. 저장하면 개인 포도와 Host 화면에 즉시 반영된다.

선택한 사진은 브라우저에서 긴 변 1440px JPEG로 줄인 뒤 R2에 저장한다. 사진 원본 전체를 올리지 않아 모바일 데이터와 저장 공간을 줄인다.

## 테스트 방법

1. 관리자 화면에서 세션을 만들고 `전시 포도 시작`을 누른다. 갤러리 이미지가 0개여도 시작할 수 있다.
2. 참여 QR로 휴대폰 두 대 이상을 접속하고 각자 닉네임을 만든다.
3. 각 휴대폰에서 서로 다른 사진과 전시 이름을 등록한다.
4. 같은 전시를 집계하려면 전시 이름과 장소를 동일하게 적는다. Host의 플립 숫자가 `02`로 바뀌는지 확인한다.
5. 리모컨에서 `참여자 전시 포도`, `전체 포도밭`, `실시간 전시 카운터`를 차례로 확인한다.

실제 행사 전에 Firebase Console의 `Authentication → Sign-in method → Anonymous`를 한 번 활성화해야 한다. 익명 로그인 토큰으로 참여자마다 제한된 R2 업로드 주소를 발급하므로 관리자 계정이나 R2 비밀키는 참여자에게 노출되지 않는다.

## NFC 방식

NFC는 이제 전시 데이터베이스를 찾는 카드가 아니라 등록 화면을 빠르게 여는 선택 기능이다. 관리자 리모컨의 `공용 NFC 주소 복사`를 눌러 아래 형태의 주소를 카드에 URL 레코드로 기록한다.

```text
https://salon.unframe.kr/client/{sessionId}?add=1&nfc=1
```

카드마다 이름만 미리 채우고 싶다면 URL 인코딩한 제목과 장소를 붙일 수 있다. 사진은 언제나 참여자가 직접 선택한다.

```text
https://salon.unframe.kr/client/{sessionId}?add=1&nfc=1&title={전시명}&venue={장소}
```

- iPhone은 잠금 해제 후 태그하면 Safari에서 등록 화면을 연다.
- Android도 URL 태그 방식이 기본이며, 지원되는 Chrome에서는 화면 안 `스캔` 버튼도 쓸 수 있다.
- NFC가 없어도 `사진으로 전시 추가` 버튼으로 모든 활동을 동일하게 수행할 수 있다.

## 저장과 Host 집계

각 참여자 문서의 `grapeSelections`에 사진 URL과 참여자가 작성한 정보를 함께 저장한다.

```js
grapeSelections: {
  grapeId: {
    id: 'grapeId',
    title: '전시 이름',
    venue: '장소',
    photoUrl: 'https://R2-public-url/.../photo.jpg',
    photoPath: 'sessions/.../grape/.../photo.jpg',
    status: 'want' | 'expecting' | 'seen',
    rating: 1,
    source: 'participant' | 'nfc',
    createdAt,
    updatedAt,
  }
}
```

Host는 전시 이름과 장소를 공백·대소문자를 정리해 자동 집계한다. 같은 전시라도 표기가 크게 다르면 별도 카드가 되므로, NFC에 제목을 미리 넣는 방식은 집계 정확도를 높이고 싶을 때만 선택하면 된다.

## 화면 구성

- `실시간 전시 카운터`: 참여자가 만든 전시 카드를 자동으로 모으고 참여 인원을 플립 숫자로 표시
- `참여자 전시 포도`: 한 사람이 직접 찍은 사진으로 채운 포도와 전시 목록 표시
- `전체 전시 포도밭`: 결과가 있는 모든 참여자의 포도송이를 하나의 줄기에 배치
