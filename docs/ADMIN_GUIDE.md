# 관리자 빠른 사용법

## 행사 준비

1. 세션을 만들고 포스터를 선택합니다.
2. `세션 준비 → 포스터·테마`에서 대표색과 실제 테마 미리보기를 확인한 뒤 적용합니다.
3. `작품` 탭에서 이미지와 비공개 실제 작품 정보를 등록하고 순서를 정합니다.
4. `PDF` 탭에서 발표 자료를 등록하고 페이지 수와 인식된 링크 수를 확인합니다.
5. `접속·QR`에서 Host, 참여자 QR, 관리자 리모컨을 점검합니다.

## 작품 제목 활동

1. 작품 카드의 `화면에 띄우기`
2. 하단 고정 컨트롤 또는 리모컨에서 `제목 받기`
3. 제출 개수를 확인하고 `투표`
4. 충분히 투표한 뒤 `정답 공개`
5. 실제 작품명·작가·설명은 공개 단계 전까지 관리자 전용 데이터에만 보관됩니다.

## PDF 발표

1. PDF 카드의 `발표 시작`
2. 관리자 화면 또는 리모컨에서 이전·다음/페이지 번호로 이동
3. 화면 맞춤·너비 맞춤·확대/축소 사용
4. 현재 페이지에 링크가 있으면 `현재 페이지 링크`에서 바로 열기
5. 잠시 화면을 숨길 때 `화면 가리기`, 종료할 때 `질문 화면`

## 현장 안전 기능

- 관리자 페이지 하단 빠른 컨트롤은 모든 탭에서 유지됩니다.
- 모바일 리모컨은 명령 처리 중 연속 입력을 막습니다.
- `화면 켜두기`를 누르면 지원 브라우저에서 휴대폰 자동 잠금을 방지합니다.
- 연결이 끊기면 리모컨 상단 상태가 즉시 바뀝니다.
